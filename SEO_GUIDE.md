## 🚀 Langkah Selanjutnya (PENTING!)

### Step 1: Setup Google Search Console
1. Buka https://search.google.com/search-console
2. Klik "Add Property"
3. Masukkan URL: `https://veralex.com`
4. Verifikasi dengan salah satu metode:
   - **HTML file upload** (recommended)
   - **HTML tag** - tambah meta tag di head
   - **DNS verification**
5. Submit sitemap: `https://veralex.com/sitemap.xml`

### Step 2: Buat Sitemap.xml
Buat file `sitemap.xml` di root folder:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://veralex.com/</loc>
    <lastmod>2026-01-25</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://veralex.com/gallery.html</loc>
    <lastmod>2026-01-25</lastmod>
    <changefreq>monthly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
```

### Step 3: Buat robots.txt
Buat file `robots.txt` di root folder:
```
User-agent: *
Allow: /
Sitemap: https://veralex.com/sitemap.xml
```

### Step 4: Setup Google Business Profile
1. Buka https://business.google.com
2. Klik "Manage now" atau "Add your business"
3. Isi informasi bisnis:
   - Nama: VERALEX CONSULTING

## 📊 Monitoring SEO

### Tools yang Digunakan:
1. **Google Search Console** - Monitor ranking & clicks
2. **Google Analytics** - Track visitors
3. **Ahrefs/Semrush** - Keyword research (optional)
4. **PageSpeed Insights** - Check loading speed

### KPI yang Dipantau:
- Impressions (tampilan di Google)
- Clicks (klik ke website)
- Average position (ranking rata-rata)
- Click-through rate (CTR)
- Organic traffic
