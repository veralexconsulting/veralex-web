**Known, accepted exceptions (not fixed, with reason):**

- `/_global-error` — the error shell. It intentionally has no metadata; Next
  cannot render one from it.
- 10 `/admin/*` + `/reset-password` pages have **no `<h1>`**. They are
  authenticated `noindex` app screens, not landing pages. Adding an `<h1>` there
  is a UI change with no indexing benefit, so it is left alone.
- `/auth/login`, `/auth/register` and `/admin/*` share the site-wide title and
  description because they inherit from the root layout. Harmless: all are
  `noindex`.
