# Sitemap submission checklist — Google Search Console

Do this once now, then on the cadence at the bottom. Nothing here can be done
from the repo: it is all dashboard work.

**Current sitemap:** `https://www.veralexconsulting.com/sitemap.xml`
— 50 URLs, generated by `src/app/sitemap.ts`, includes `xhtml:link` hreflang
alternates for the 8 translated locale pages.

---

## 1. Property setup (5 min, once)

- [ ] Open <https://search.google.com/search-console>.
- [ ] Confirm there is a property for **`https://www.veralexconsulting.com`**.
      If only a **Domain** property (`veralexconsulting.com`) exists, that one
      also works and covers www + apex — but use the **URL-prefix** property for
      sitemap pings so the numbers match the canonical host.
- [ ] If neither exists: **Add property → URL prefix →
      `https://www.veralexconsulting.com`**.
- [ ] Verify ownership. Easiest on Vercel: **Domain** property with a DNS TXT
      record, added in the registrar or Vercel → Settings → Domains → DNS.
      (URL-prefix properties can also use the HTML tag method, which needs a
      code change — the DNS route avoids that.)
- [ ] Make sure the same Google account has access if a different person runs
      the Ads account, so organic and paid data can be compared.

## 2. Submit the sitemap (2 min)

- [ ] Left menu → **Indexing → Sitemaps**.
- [ ] In "Add a new sitemap", enter `sitemap.xml` (the prefix is filled in).
- [ ] **Submit**. Status should go to **Success** within a few minutes to a day.
- [ ] Confirm the reported count reads **50** URLs. If it says "Couldn't fetch",
      open `https://www.veralexconsulting.com/sitemap.xml` in a browser first —
      it must return XML, not a redirect or a 404.

## 3. Sanity checks in the same session

- [ ] **Indexing → Pages**: note the "Not indexed" reasons before and after.
      Expect "Excluded by 'noindex'" to grow by up to 34 — those are the
      untranslated `/en` and `/zh` service pages, which is correct (see
      `docs/DECISIONS.md`, 2026-11-12).
- [ ] **URL Inspection** → paste `https://www.veralexconsulting.com/` →
      **Test live URL**. Expect: "URL is available to Google", the canonical
      shown as the same URL.
- [ ] **URL Inspection** → paste `https://veralexconsulting.com/` (no www).
      Expect "Page with redirect".
- [ ] **Enhancements** (left menu): confirm **FAQ**, **Breadcrumbs**, **Sitelinks
      search box** items appear if applicable. Ignore items with 0 valid items.

## 4. After the canonical-host 308 is live (see `docs/CANONICAL-HOST.md`)

- [ ] Wait 2–4 weeks for re-crawl, then re-check **Indexing → Pages** for
      "Duplicate, Google chose different canonical" pointing at apex URLs.
- [ ] Do **not** use "Change of address" — no domain is moving, only the
      redirect status.

## 5. Ongoing cadence

| When | Action |
|---|---|
| After any deploy that adds/removes a page | Sitemap re-reads automatically; nothing to resubmit. Check **Indexing → Pages** weekly. |
| Monthly | Skim **Indexing → Pages → Not indexed** for new reasons. "Crawled – currently not indexed" on a service page is the signal to look at content, not config. |
| Monthly | **Experience → Core Web Vitals** — confirm mobile LCP/CLS/INP are in "Good" for the four money pages (home, pt-pma, pendaftaran-merek, kitas-kerja). |
| After a locale page is translated | Confirm it leaves "Excluded by 'noindex'" (it flips automatically once the copy exists — see `docs/DECISIONS.md`). |

## 6. Things that will look like problems but are not

- **34 URLs "Excluded by noindex"** — the untranslated EN/ZH service pages.
  Intended.
- **Apex URLs showing as redirects** — intended; www is canonical.
- **`/_global-error` and `/admin/*` never appearing** — they are `noindex` app
  screens, not content.
